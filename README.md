# Seba Ghor — Digital Household Service Management Platform

A home-service marketplace for Dhaka where users can find verified helpers (cleaner, cook, electrician, plumber). Developed as a team project for the Project Management course using a Waterfall + Agile hybrid approach.

🔗 **Live website:** https://tahsinstudy26-ux.github.io/Seba_Ghor/seba-ghor.html

## Overview
Seba Ghor is designed around trust and safety for household services. The project includes a project management plan (charter, WBS, Gantt chart, risk and budget plans) and a front-end website prototype.

## Website Features
- Service listings (house cleaning, cooking, electrician, plumbing)
- Helper profiles with ratings and verification badges
- 5-step provider verification and 3-layer safety framework
- Provider registration section and customer testimonials
- Responsive design for mobile and desktop

## Technologies
- HTML5, CSS3 (Flexbox, Grid, media queries)
- JavaScript (mobile navigation menu)
- Font Awesome icons, Google Fonts
- Hosted on GitHub Pages

## Project Management
- **Methodology:** Waterfall + Agile hybrid
- **Tools:** Trello (Kanban board)
- **Timeline:** 4 months (January to April 2026)

## Note
The website is a front-end prototype. Login, booking, and registration buttons are not connected to a backend or database.
